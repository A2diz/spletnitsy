# CLAUDE.md — Правила проекта

Этот файл описывает правила и стандарты проекта для Claude.
Читай его перед любым действием в репозитории.

---

## Стек проекта

- **Основной язык:** HTML, CSS, JavaScript (vanilla)
- **В будущем возможно:** добавление других технологий (обновляй этот раздел при изменениях)

---

## При ревью Pull Request проверяй:

### HTML
- Валидная семантическая разметка (используй `<header>`, `<main>`, `<section>`, `<article>` и т.д.)
- Наличие `alt` у всех `<img>`
- Наличие `lang` атрибута у `<html>`
- Правильная структура заголовков (h1 → h2 → h3, без пропусков)
- Мета-теги: `charset`, `viewport`, `description`, `title`

### CSS
- Нет инлайн-стилей (`style="..."`) — только классы
- Нет !important без крайней необходимости
- Адаптивность: проверь наличие media queries для мобильных
- Переменные CSS (`--var`) для цветов и отступов

### JavaScript
- Нет `console.log` в продакшн-коде
- Обработка ошибок в fetch/async операциях
- Нет глобальных переменных без необходимости

### Безопасность
- Нет хардкода ключей, паролей, токенов
- XSS: нет `innerHTML` с пользовательскими данными без санитизации

### Производительность
- Изображения оптимизированы (предпочитать WebP/SVG)
- Внешние шрифты подключены через `preconnect`
- JS-скрипты с `defer` или `async`

---

## При создании файлов и кода:

- Следуй существующей структуре папок проекта
- Создавай новые HTML-страницы с полным базовым шаблоном (DOCTYPE, head, meta, title)
- Добавляй комментарии к сложным блокам CSS/JS
- После создания файлов — всегда открывай Pull Request, не коммить напрямую в main/master
- В описании PR кратко опиши: что создано, зачем, что проверить

---

## При генерации тестов:

- Проверяй наличие ключевых HTML-элементов
- Тестируй доступность (aria-labels, роли)
- Для JS-функций пиши unit-тесты

---

## При обновлении документации:

- Обновляй `README.md` при добавлении новых страниц или компонентов
- Описывай структуру папок если она меняется
- Добавляй скриншоты или описание UI если это уместно

---

## Язык общения

- Все комментарии в PR и ответы в issues — **на русском языке**
